FuniAR — AR Furniture Viewer:

Aplikasi web AR (Augmented Reality) untuk menampilkan model 3D furniture (lemari, meja, sofa) di dunia nyata menggunakan marker fisik yang di-scan lewat kamera. Dibangun dengan A-Frame + AR.js, tanpa perlu install aplikasi native — cukup buka lewat browser.

Demo Konsep:

Arahkan kamera HP/laptop ke salah satu marker yang sudah dicetak, model 3D furniture yang sesuai akan langsung muncul menempel di atas marker tersebut.

Fitur:
- Marker tracking custom (bukan cuma Hiro bawaan) — 1 marker fisik = 1 furniture
- Load model 3D asli format .glb (hasil export dari Blender)
- UI overlay: status deteksi marker, tombol info furniture, placement helper
- Bisa dijalankan langsung dari browser tanpa build tool
